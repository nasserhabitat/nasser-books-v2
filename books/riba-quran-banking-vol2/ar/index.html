الحالة العلمية الحاكمة

BANK (البنك) ≠ SINGLE (مفرد) TRANSACTION (المعاملة)

BANK (البنك) ≠ SINGLE (مفرد) FUNCTION (الوظيفة)

INSTITUTION (المؤسسة) ≠ PRODUCT (المنتج)

PRODUCT (المنتج) ≠ CASE (الحالة)

BANK (البنك) LABEL (الاسم الدال) ≠ QURANIC CLASSIFICATION (تصنيف قرآني)

BANK (البنك) FUNCTION (الوظيفة) ≠ RIBA DEFINITION (تعريف الربا)

APPLICATION VARIABLE (متغير تطبيقي) ≠ QURANIC LAW (قانون قرآني)

RIBA-QTAM (نموذج تدقيق المعاملة القرآني) v0.1 = STRUCTURAL AUDIT MODEL (نموذج تدقيق بنيوي)

RIBA CLASSIFICATION READINESS (جاهزية تصنيف الربا) = OPEN (مفتوح) / NOT PASSED (غير مجتاز)

ISLAMIC (إسلامي) BANKING (مصرفي) RIBA-CLASSIFICATION / RULING (الحكم) LAB (المختبر) = LOCKED (مقفل)

CONTEMPORARY (معاصر) TRANSACTION (المعاملة) STRUCTURAL AUDIT (التدقيق البنيوي) LAB (المختبر) = UNLOCKED

RIBA FINAL DEFINITION (التعريف النهائي للربا) = NOT SEALED (غير مغلق)

الحالة العلمية المجمدة من الأبواب السابقة:

• RIBA FINAL DEFINITION (التعريف النهائي للربا) = NOT SEALED (غير مغلق)

• DEBT SUFFICIENCY (كفاية الدين) = RESISTED (قاوم الاختبار/مقاوَم)

• TIME (الزمن) / TERM SUFFICIENCY (كفاية الأجل) = RESISTED (قاوم الاختبار/مقاوَم)

• INCREASE SUFFICIENCY (كفاية الزيادة) = RESISTED (قاوم الاختبار/مقاوَم)

• NAME (الاسم) ≠ STRUCTURE (البنية)

• TRANSACTION (المعاملة) CASE (الحالة) = PRIMARY (أولي) UNIT (الوحدة) OF ANALYSIS (التحليل)
